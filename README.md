## 🚀 Projects

### 🔹 AskDocs (AI Document Chatbot)
An AI-powered document chatbot built using Retrieval-Augmented Generation (RAG) that enables users to chat with PDF documents.
- Implemented document chunking and semantic retrieval using vector embeddings
- Retrieves the most relevant document chunks using cosine similarity search
- Generates context-aware responses using Large Language Models (LLMs)
- Built with Node.js, Express, OpenAI Embeddings, and PDF parsing

### 🔹 Cross-Resolution Consistency Learning
Deep Learning project that evaluates how different neural network architectures perform across low- and high-resolution images.
- Compared CNN, ResNet, and Vision Transformer (ViT) models
- Analyzed model robustness and consistency across multiple image resolutions
- Evaluated performance using standard classification metrics
- Focused on understanding resolution sensitivity of modern vision models

### 🔹 Few-Shot Learning for Brain Tumor Segmentation
Medical image segmentation project on the BraTS MRI dataset using Few-Shot Learning techniques.
- Performed brain tumor segmentation with limited annotated training samples
- Leveraged nnU-Net architecture for medical image segmentation
- Evaluated performance using Dice Similarity Coefficient (DSC)
- Explored Few-Shot Learning for data-efficient medical image analysis
